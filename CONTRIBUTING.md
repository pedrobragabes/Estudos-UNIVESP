# Contribuição

1. Crie uma branch curta a partir de `main`.
2. Faça alterações pequenas e focadas.
3. Execute `npm run check`.
4. Use commits semânticos, como `feat:`, `fix:`, `refactor:` e `docs:`.
5. Abra um pull request descrevendo problema, solução e validação.

Não adicione novas funcionalidades sem demonstrar relação direta com o objetivo acadêmico central.
