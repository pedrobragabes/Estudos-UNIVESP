# COM230 · Semana 1 · Paradigmas, classes, objetos e ambiente Java

Explicações e exercícios autorais baseados nas fontes consultadas em 02/11/2026. A análise integral de livros, vídeos e lives permanece pendente; confira os status abaixo.

## Síntese

Paradigmas oferecem modos de organizar soluções; POO agrupa estado e comportamento em objetos.

Classe define estrutura e operações; objeto é uma instância com identidade e estado.

Java compila fonte em bytecode executado pela JVM; ferramentas ajudam, mas não substituem o modelo conceitual.

## Objetivos

- Comparar programação não estruturada, estruturada e orientada a objetos.
- Relacionar estado e comportamento em classes e instâncias.
- Distinguir JDK, JVM, IDE, biblioteca e framework e executar um programa.

## Organização dos programas

Programação não estruturada depende de saltos e controle pouco delimitado. A estruturada organiza sequência, seleção e repetição em blocos e subprogramas. POO modela entidades e responsabilidades, combinando dados e operações.

Os paradigmas coexistem: métodos Java usam decisões e laços. POO não elimina algoritmos nem garante qualidade por si só. A escolha de objetos deve refletir responsabilidades do problema.

## Classes, objetos e referências

Uma classe define atributos e métodos. Cada instância pode ter estado diferente. Identidade distingue objetos que podem ter valores iguais. Uma variável de referência aponta para um objeto; atribuí-la a outra variável não cria uma cópia da instância.

No exemplo, ana e bia são objetos independentes. A variável mesma referencia o mesmo objeto que ana. Alterar esse objeto por uma referência torna a mudança observável pela outra. Atribuir um int, em comparação, copia seu valor.

## Do fonte à execução

O JDK fornece javac e java; a JVM executa bytecode. Uma IDE integra edição, compilação e depuração. Bibliotecas oferecem recursos chamados pelo programa; frameworks definem parte da estrutura e do fluxo da aplicação.

Salve em Main.java, compile com javac -encoding UTF-8 Main.java e execute java Main. A classe pública corresponde ao nome do arquivo. Os exemplos usam recursos compatíveis com Java 8, coerentes com as referências do curso.

## Programa completo e saída

A saída é Ana: 1, Bia: 0 e true. O contador de ana muda pelo acesso via mesma. O operador == compara identidade de referências nesse caso; conteúdo de objetos, quando pertinente, é comparado por equals.

main é static e oferece entrada ao programa. Os campos comuns pertencem às instâncias. Desenhe os objetos criados por new e as setas das referências antes de prever a saída.

```java
public class Main {
    static class Aluno {
        String nome;
        int revisoes;
        Aluno(String nome) { this.nome = nome; }
        void revisar() { revisoes++; }
    }
    public static void main(String[] args) {
        Aluno ana = new Aluno("Ana");
        Aluno bia = new Aluno("Bia");
        Aluno mesma = ana;
        mesma.revisar();
        System.out.println(ana.nome + ": " + ana.revisoes);
        System.out.println(bia.nome + ": " + bia.revisoes);
        System.out.println(ana == mesma);
    }
}
```

## Prática comentada

### 1. Após Aluno outra=ana; outra.revisar(); o que muda?

1. A atribuição copia a referência, sem executar new.
2. As variáveis observam o mesmo objeto; ana passa a 2 revisões.
3. Bia continua independente.

### 2. Modele um livro sem reunir todo o sistema em uma classe.

1. Estado relevante: título e disponibilidade.
2. Operações: emprestar e devolver, com responsabilidades claras.
3. Leitores, catálogo e empréstimos podem ter outras responsabilidades.

### 3. Diferencie falha de compilação de falha em execução.

1. Variável não declarada impede compilar.
2. Acesso a índice inválido pode falhar durante a execução.
3. Compilar não comprova comportamento correto; leia a mensagem e localize a origem.

## Erro comum

Classe e objeto não são sinônimos. Atribuir uma referência não clona o objeto.

## Flashcards

- **Classe e objeto?** Classe define estrutura e comportamento; objeto é uma instância.
- **O que new faz?** Cria uma instância e produz sua referência após inicialização.
- **Copiar referência clona o objeto?** Não; duas variáveis podem observar a mesma instância.
- **JDK?** Conjunto de ferramentas de desenvolvimento, incluindo compilador.
- **JVM?** Ambiente que executa bytecode Java.
- **Biblioteca e framework?** Biblioteca oferece recursos chamados pelo programa; framework organiza parte do fluxo e chama código da aplicação.

## Questões autorais

### 1. Duas variáveis com a mesma referência:

A. Podem observar mudanças no mesmo objeto.
B. Sempre apontam para cópias.
C. Transformam a classe em static.
D. Impedem chamadas de método.

**Gabarito:** A. A referência é copiada, mas a instância continua compartilhada.

### 2. Qual comando compila Main.java?

A. javac Main.java
B. java Main em Java 8.
C. jvm compile Main
D. javac Main.class

**Gabarito:** A. javac transforma fonte em bytecode; java Main executa o resultado no modelo usado aqui.

### 3. Um método Java com for mostra que:

A. POO pode usar estruturas da programação estruturada.
B. Laços não existem em POO.
C. Toda classe é framework.
D. Objetos são proibidos nesse método.

**Gabarito:** A. Paradigmas podem se combinar; métodos contêm seleção, sequência e repetição.

### 4. Qual possui estado particular de uma instância?

A. Objeto.
B. Nome do pacote apenas.
C. Compilador apenas.
D. Arquivo de configuração da IDE apenas.

**Gabarito:** A. A classe define campos; as instâncias têm valores próprios para campos de instância.
